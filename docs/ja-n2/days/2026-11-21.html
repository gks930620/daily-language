十一月も半ばを過ぎると、書店や文具店の一角は来年の手帳でにわかに華やぐ。スマートフォンで予定を管理するのが当たり前になった今でも、紙の手帳を手放せないという人は決して少なくない。売り場で何冊も見比べ、ページのレイアウトや紙の書き味を確かめては迷う時間そのものが、年の瀬を前にしたささやかな楽しみなのだろう。もっとも、心機一転と意気込んで買ったはいいが、春先には白紙のページばかりが目立つというのも、毎年お決まりの光景である。それでも懲りずにまた新しい一冊を選んでしまうのは、手帳が予定を書き込む道具である以上に、まだ見ぬ一年への期待を託す器だからに違いない。

  1. 十一月も半ばを過ぎると、書店や文具店の一角は来年の手帳でにわかに華やぐ。

    해석 · 단어 · 구문 분석

    十一月(じゅういちがつ)も半(なか)ばを過(す)ぎると、書店(しょてん)や文具店(ぶんぐてん)の一角(いっかく)は来年(らいねん)の手帳(てちょう)でにわかに華(はな)やぐ。

    11월도 중순을 넘기면, 서점과 문구점 한쪽은 내년 수첩으로 갑자기 화사해진다.

    단어

    • 一角 — 한구석, 한쪽 구역(いっかく)
    • にわかに — 갑자기, 별안간(문어적)
    • 華やぐ — 화사해지다, 활기를 띠다

    구문 분석

    · ~も半ばを過ぎると : '~도 절반(중순)을 넘기면'. も가 '벌써 그만큼 왔다'는 시간 경과의 감회를 더한다. 한국어 '11월도 중순이 지나면'과 거의 같은 감각. · ~と : 자연스럽게 반복되는 계절 현상을 말하는 조건. '~하면 (어김없이)'. · にわかに華やぐ : 수필·기사체의 묘사. にわかに(갑자기)는 急に보다 문어적이고, 華やぐ는 장소·분위기가 '화사해지다'라는 자동사. 주어가 사람이 아니라 '매장 한쪽'인 점이 일본어다운 풍경 묘사.

  2. スマートフォンで予定を管理するのが当たり前になった今でも、紙の手帳を手放せないという人は決して少なくない。

    해석 · 단어 · 구문 분석

    スマートフォンで予定(よてい)を管理(かんり)するのが当(あ)たり前(まえ)になった今(いま)でも、紙(かみ)の手帳(てちょう)を手放(てばな)せないという人(ひと)は決(けっ)して少(すく)なくない。

    스마트폰으로 일정을 관리하는 것이 당연해진 지금도, 종이 수첩을 놓지 못한다는 사람은 결코 적지 않다.

    단어

    • 当たり前 — 당연함
    • 決して~ない — 결코 ~않다

    구문 분석

    · ~のが当たり前になった今でも : '~하는 게 당연해진 지금도'. 시대 변화를 인정하면서 반대 경향을 꺼낼 때의 기사체 도입 패턴. · 手放せない : 手放す(손에서 놓다)의 가능 부정. 물리적으로 '버리지 못한다'를 넘어 '그것 없이는 못 지낸다'는 애착 표현. · 決して少なくない : 이중 부정에 가까운 완곡 긍정. '많다'고 단정하지 않고 '결코 적지 않다'로 신중하게 말하는 것이 일본어 신문·에세이 문체의 전형.

  3. 売り場で何冊も見比べ、ページのレイアウトや紙の書き味を確かめては迷う時間そのものが、年の瀬を前にしたささやかな楽しみなのだろう。

    해석 · 단어 · 구문 분석

    매장에서 몇 권이고 비교해 보며, 페이지 구성이나 종이의 필기감을 확인하고는 망설이는 시간 그 자체가, 연말을 앞둔 소소한 즐거움인 것이리라.

    단어

    • 見比べる — 비교해 보다
    • 書き味 — 필기감, 써지는 느낌

    구문 분석

    · 見比べ、 : 연용형 중지. て형(見比べて) 대신 연용형으로 문장을 잇는 것은 문어체의 표지 — 기사·수필에서 자주 보인다. · ~ては迷う : ~ては+동사는 '~하고는 ~하기를 반복하다'. 確かめては迷う = '확인했다가 또 망설였다가'. 한 번의 동작이 아니라 되풀이를 그린다. · ~そのもの : '~그 자체'. 결과(산 수첩)가 아니라 고르는 '시간 자체'가 즐거움이라고 초점을 옮긴다. · ~を前にした : '~를 앞둔'. 명사 수식형으로 쓰여 年の瀬を前にした楽しみ = '연말을 앞둔 즐거움'. · ~なのだろう : 필자의 부드러운 추측·납득. 단정을 피하면서 독자의 공감을 구하는 수필 어조.

  4. もっとも、心機一転と意気込んで買ったはいいが、春先には白紙のページばかりが目立つというのも、毎年お決まりの光景である。

    해석 · 단어 · 구문 분석

  5. それでも懲りずにまた新しい一冊を選んでしまうのは、手帳が予定を書き込む道具である以上に、まだ見ぬ一年への期待を託す器だからに違いない。

    해석 · 단어 · 구문 분석

    단어

    • 懲りる — (데어서) 질리다, 넌더리 나다
    • まだ見ぬ — 아직 보지 못한(문어)
    • 器 — 그릇; (비유) 담는 것

    구문 분석

    · 懲りずに : 懲りる(데어서 다시는 안 하려 하다)의 부정 연용형. '혼나고도 또'라는 애정 어린 자조. · ~のは、~からに違いない : '~하는 것은 ~이기 때문임에 틀림없다'. 현상→이유를 강한 확신으로 맺는 수필의 결론 문형. からだ보다 단정의 감정이 강하다. · ~である以上に : '~이라는 것 이상으로'. 기능적 정의(도구)를 넘어선 의미(그릇)를 대비시킨다. 여기서 以上に는 '~하는 이상(=~한 바에는)'의 以上と 다르다는 점에 주의. · まだ見ぬ : 문어 부정 조동사 ぬ(=ない)의 연체형. まだ見ない의 시적·문어적 표현으로 まだ見ぬ世界·まだ見ぬ未来처럼 굳은 표현이 많다.

💡 心機(마음의 움직임)+一転(한 번 확 바뀜). 新規一転으로 잘못 쓰는 일이 많은 사자성어 — '새로울 新'이 아니라 '마음 心'이다.
구분気分転換(기분 전환) — 気分転換은 일시적으로 기분을 바꾸는 것, 心機一転은 계기를 맞아 마음가짐 자체를 새로 하는 것

仕切り直す しきりなおす 동 처음부터 다시 하다, 재정비해 새로 시작하다

議論が行き詰まったので、来週改めて仕切り直すことにした。
논의가 막혀서 다음 주에 다시 처음부터 하기로 했다.

💡 스모에서 선수들이 호흡이 안 맞아 立ち合い(맞붙기)를 다시 하는 '仕切り直し'에서 나온 말. 그래서 '일단 멈추고 다시 맞춰 시작'이라는 뉘앙스.
파생仕切り直し(명) 재시작, 다시 함
구분やり直す(다시 하다) — やり直す는 잘못된 것을 고쳐 다시 함, 仕切り直す는 흐름을 끊고 태세를 정비해 재출발함

押し迫る おしせまる 동 (기한·연말이) 바싹 다가오다

年も押し迫った十二月二十八日、ようやく大掃除に取りかかった。
연말이 바싹 다가온 12월 28일, 겨우 대청소에 착수했다.

💡 迫る에 押し(밀어붙이다)가 붙어 '밀려오듯 임박함'이 강조된다. 특히 '年も押し迫った~'는 연말 뉴스·인사말의 단골 표현.
구분差し迫る(임박하다) — 差し迫る는 위험·필요가 긴박하게 닥침(差し迫った危機), 押し迫る는 주로 연말·기한 같은 시간이 다가옴
