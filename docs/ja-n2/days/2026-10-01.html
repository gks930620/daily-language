  1. 十月一日は「日本酒の日」だが、この日を祝うべき酒蔵の数は、ここ半世紀で半分以下にまで減っている。

    해석 · 단어 · 구문 분석

    十月一日(じゅうがつついたち)は「日本酒(にほんしゅ)の日(ひ)」だが、この日(ひ)を祝(いわ)うべき酒蔵(さかぐら)の数(かず)は、ここ半世紀(はんせいき)で半分(はんぶん)以下(いか)にまで減(へ)っている。

    10월 1일은 '일본술의 날'이지만, 이날을 축하해야 할 양조장의 수는 최근 반세기 사이에 절반 이하로까지 줄었다.

    단어

    • 酒蔵 — 양조장, 술도가
    • ~べき — 마땅히 ~해야 할

    구문 분석

    · ~べき : '마땅히 ~해야 할'. 祝うべき酒蔵 = '(본래라면) 이날을 축하해야 할 당사자인 양조장' — 주인공이 오히려 줄고 있다는 아이러니를 만든다. · ここ半世紀で : ここ+기간 = '최근 ~ 동안'. ここ数年·ここ十年처럼 현재까지 이어지는 기간. · ~にまで : に(도달점)+まで(극단) — '~에까지'. 감소 폭이 예상 이상임을 강조한다.

  2. 若者の酒離れが言われて久しく、会社帰りに上司と酒を酌み交わすどころか、飲み会そのものを断る人も珍しくない。

    해석 · 단어 · 구문 분석

    若者(わかもの)の酒離(さけばな)れが言(い)われて久(ひさ)しく、会社帰(かいしゃがえ)りに上司(じょうし)と酒(さけ)を酌(く)み交(か)わすどころか、飲(の)み会(かい)そのものを断(ことわ)る人(ひと)も珍(めずら)しくない。

    젊은이들의 '술 멀리하기'가 거론된 지도 오래여서, 퇴근길에 상사와 술잔을 주고받기는커녕 회식 자체를 거절하는 사람도 드물지 않다.

    단어

    • 酒離れ — 술을 멀리하는 경향
    • 酌み交わす — 술잔을 주고받다
    • ~て久しい — ~한 지 오래다

    구문 분석

    · ~て久しい : N1 문형 '~한 지 오래다'. 言われて久しく는 연용형 중지로 뒤 문장에 이어진다. 기사체에서 '새삼스럽지 않은 현상'을 꺼낼 때의 정형구. · ~どころか : '~은커녕'. 앞(술잔을 주고받기)보다 훨씬 더한 뒤(회식 자체를 거절)를 들어 정도 차이를 강조. · そのもの : 명사+そのもの = '~ 자체'. 한국어 '자체'와 거의 1:1.

  3. 家で晩酌をする習慣も薄れ、国内の消費量は右肩下がりの一途をたどっている。

    해석 · 단어 · 구문 분석

    家(いえ)で晩酌(ばんしゃく)をする習慣(しゅうかん)も薄(うす)れ、国内(こくない)の消費量(しょうひりょう)は右肩下(みぎかたさ)がりの一途(いっと)をたどっている。

    집에서 저녁 반주를 하는 습관도 옅어져, 국내 소비량은 계속 내리막길만 걷고 있다.

    단어

    • 晩酌 — 저녁 반주
    • 一途をたどる — 한 방향으로 계속 ~해 가다

    구문 분석

    · 薄れ : 薄れる(옅어지다)의 연용형 중지. 기억·관심·습관이 '희미해지다'에 두루 쓴다. · 右肩下がり : 그래프가 오른쪽으로 갈수록 내려가는 모양 — 한국어 '우하향'. · ~の一途をたどる : N1 문형 '(한 방향으로) 계속 ~해 가다'. 減少·悪化の一途をたどる처럼 주로 좋지 않은 추세에 쓰는 기사체 표현.

  4. それでも、杜氏たちが手間を惜しまずに醸した酒は、海外では和食ブームと相まって評価を高めており、そこに活路を見いだす蔵も少なくない。

    해석 · 단어 · 구문 분석

    それでも、杜氏(とうじ)たちが手間(てま)を惜(お)しまずに醸(かも)した酒(さけ)は、海外(かいがい)では和食(わしょく)ブームと相(あい)まって評価(ひょうか)を高(たか)めており、そこに活路(かつろ)を見(み)いだす蔵(くら)も少(すく)なくない。

    그래도 도지(술 빚기 장인)들이 수고를 아끼지 않고 빚은 술은 해외에서 일식 붐과 맞물려 평가를 높이고 있고, 거기서 활로를 찾는 양조장도 적지 않다.

    단어

    • 杜氏 — 도지, 술 빚기 총책임 장인
    • 醸す — (술을) 빚다
    • 活路を見いだす — 활로를 찾다

    구문 분석

    · 手間を惜しまずに : 惜しむ(아끼다)의 부정 ~ずに = '수고를 아끼지 않고'. 장인 정신을 말할 때의 단골 표현. · ~と相まって : '~과 맞물려, ~이 더해져'. 두 요인이 겹쳐 효과가 커질 때 쓰는 N1 문형. · 高めており : ~ている의 문어체 연결형 ~ており. 기사·보고서에서 쉼표 앞에 자주 온다. · 蔵 : 문맥상 酒蔵의 줄임. 업계·기사에서는 蔵만으로 양조장을 가리킨다.

  5. 下戸でも飲みやすい低アルコールの酒を仕込む蔵も現れ始めた今、量を競う時代は終わり、酒は「嗜む」ものへと姿を変えつつあるのだろう。

    해석 · 단어 · 구문 분석

    下戸(げこ)でも飲(の)みやすい低(てい)アルコールの酒(さけ)を仕込(しこ)む蔵(くら)も現(あらわ)れ始(はじ)めた今(いま)、量(りょう)を競(きそ)う時代(じだい)は終(お)わり、酒(さけ)は「嗜(たしな)む」ものへと姿(すがた)を変(か)えつつあるのだろう。

    술을 못 하는 사람도 마시기 쉬운 저알코올 술을 빚는 양조장까지 나타나기 시작한 지금, 양을 겨루는 시대는 끝나고 술은 '음미하며 즐기는' 것으로 모습을 바꾸어 가고 있는 것이리라.

    단어

    • 下戸 — 술을 못 마시는 사람
    • 仕込む — (술 등을) 담그다
    • 嗜む — (적당히·품위 있게) 즐기다

    구문 분석

    · ~始めた今 : 동사 과거형+今 = '~하기 시작한 지금'. 시점을 명사 今으로 묶어 결론부로 넘어가는 칼럼식 연결. · ~へと : 방향 へ+と — '~으로(바뀌어)'. 変わる·移る 같은 변화 동사 앞에서 문어적 무게를 더한다. · ~つつある : N1 문형 '~하고 있는 중이다'(변화가 진행 중). ~ている보다 '서서히 진행되는 흐름'을 강조한다. · ~のだろう : 필자의 추론으로 단락을 닫는 칼럼의 전형적인 맺음.

盛り返す もりかえす 동 (기세를) 되찾다, 만회하다

前半は劣勢だったが、後半に入って一気に盛り返した。
전반에는 열세였지만 후반 들어 단숨에 만회했다.

💡 盛る(높이 쌓다)+返す(되돌리다) — 무너진 것을 다시 쌓아 올리는 이미지. 人気・勢いを盛り返す처럼 '기세'가 목적어.
구분持ち直す(회복하다) — 持ち直す는 나빠지던 상태가 나아짐(경기·병세·날씨), 盛り返す는 밀리던 쪽이 기세를 되찾음(승부·인기)
