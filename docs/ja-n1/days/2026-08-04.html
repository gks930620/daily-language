생활 — 고쳐 쓰기를 잊은 시대, 동네 수선집에서(수필)

「もう部品がないんですよ」と、店主は申し訳なさそうに言いながら、私が持ち込んだ古い扇風機の羽根を丁寧に外してみせた。十数年前に買ったこの一台は、夏が来るたびに軋むような音を立てていたが、それでも捨てる気にはなれずにいた。修理より買い替えのほうが安上がりだという理屈は、頭では分かっている——分かってはいるが、どうにも割り切れない。使い捨てを前提に設計された製品に囲まれて暮らすうちに、私たちは物を直すという営みそのものを、いつの間にか手放してしまったのではないか。店主は「まあ、だましだまし使いましょう」と笑い、油を差した羽根を、元通りに嵌め直した。

  1. 「もう部品がないんですよ」と、店主は申し訳なさそうに言いながら、私が持ち込んだ古い扇風機の羽根を丁寧に外してみせた。

    해석 · 단어 · 구문 분석

    「もう部品(ぶひん)がないんですよ」と、店主(てんしゅ)は申(もう)し訳(わけ)なさそうに言(い)いながら、私(わたし)が持(も)ち込(こ)んだ古(ふる)い扇風機(せんぷうき)の羽根(はね)を丁寧(ていねい)に外(はず)してみせた。

    "이제 부품이 없어요"라고, 주인은 미안한 듯이 말하면서, 내가 들고 온 낡은 선풍기의 날개를 정성스럽게 떼어 보였다.

    단어

    • 部品 — 부품
    • 羽根 — (선풍기·새의) 날개
    • ~てみせる — ~해 보이다

    구문 분석

    · 申し訳なさそうに : ない로 끝나는 형용사에 양태의 そうだ가 붙으면 사이에 さ가 들어가 「~なさそう」가 된다(申し訳ない→申し訳なさそう). 한국어 '미안한 듯이'. · 持ち込んだ : 「動詞連用形+込む」는 '안으로 ~해 넣다'는 생산적 조어법 — 駆け込む(뛰어 들어가다)·話し込む(이야기에 빠져들다)와 같은 계열. · 外してみせた : 「~てみせる」는 '(보란 듯이) ~해 보이다'. 시도를 뜻하는 「~てみる」와 달리 상대에게 보여 주는 행위·의지를 나타낸다.

  2. 十数年前に買ったこの一台は、夏が来るたびに軋むような音を立てていたが、それでも捨てる気にはなれずにいた。

    해석 · 단어 · 구문 분석

    十数年前(じゅうすうねんまえ)に買(か)ったこの一台(いちだい)は、夏(なつ)が来(く)るたびに軋(きし)むような音(おと)を立(た)てていたが、それでも捨(す)てる気(き)にはなれずにいた。

    십수 년 전에 산 이 한 대는, 여름이 올 때마다 삐걱거리는 듯한 소리를 내고 있었지만, 그래도 버릴 마음은 도무지 들지 않은 채였다.

    단어

    • 音を立てる — 소리를 내다
    • ~ずにいる — ~하지 않은 채로 있다

    구문 분석

    · 来るたびに : 「~たびに」('~할 때마다') 앞에는 반드시 사전형이 온다 — 来たたびに라고 하지 않는다. · 軋むような音 : 「~ような」로 한 발 물러선 비유. 실제 소리를 단정하지 않고 '삐걱대는 듯한'으로 감각을 그린다. · 捨てる気にはなれずにいた : 「~気になる」(~할 마음이 들다)의 가능형 부정 なれない에 문어체 부정 「~ずにいる」(~하지 않은 채로 있다)를 겹쳤다. は는 대비 — 고칠 마음과 대비되는 '버릴 마음은'.

  3. 修理より買い替えのほうが安上がりだという理屈は、頭では分かっている——分かってはいるが、どうにも割り切れない。

    해석 · 단어 · 구문 분석

    修理(しゅうり)より買(か)い替(か)えのほうが安上(やすあ)がりだという理屈(りくつ)は、頭(あたま)では分(わ)かっている——分(わ)かってはいるが、どうにも割(わ)り切(き)れない。

    수리보다 새로 사는 편이 싸게 먹힌다는 논리는, 머리로는 알고 있다——알고는 있지만, 아무래도 딱 잘라 정리가 되지 않는다.

    단어

    • 理屈 — 이치, (말뿐인) 논리
    • どうにも~ない — 아무래도 ~할 수 없다

    구문 분석

    · ~という理屈 : 앞 내용을 '~라는 논리'로 묶어 받는 명사화. 理屈는 '이치'이면서 동시에 '마음은 따라가지 않는 말뿐인 논리'라는 냉소를 머금는다(道理와의 차이). · 頭では / 分かってはいる : 둘 다 대비의 は. '머리로는(마음으로는 아니고)', '알고는 있지만(받아들이지는 못하고)' — 앞말을 되받아 반복하며 역접을 예고하는 수필체 리듬. · どうにも~ない : '아무리 해도 ~않다'. 割り切れない(나머지 없이 정리되지 않다)와 붙어 감정의 앙금을 드러낸다.

  4. 使い捨てを前提に設計された製品に囲まれて暮らすうちに、私たちは物を直すという営みそのものを、いつの間にか手放してしまったのではないか。

    해석 · 단어 · 구문 분석

    使(つか)い捨(す)てを前提(ぜんてい)に設計(せっけい)された製品(せいひん)に囲(かこ)まれて暮(く)らすうちに、私(わたし)たちは物(もの)を直(なお)すという営(いとな)みそのものを、いつの間(ま)にか手放(てばな)してしまったのではないか。

    일회용을 전제로 설계된 제품에 둘러싸여 살아가는 사이에, 우리는 물건을 고친다는 행위 그 자체를, 어느새 놓아 버린 것은 아닐까.

    단어

    • 前提 — 전제
    • いつの間にか — 어느새
    • ~のではないか — ~한 것은 아닐까

    구문 분석

    · ~を前提に : 「~を前提に(して)」 '~를 전제로'. 논설·기사에서 쓰는 문어적 부사구. · ~うちに : '~하는 사이에' — 본인이 의도하지 않은 변화가 일어났음을 나타내며, 뒤의 いつの間にか와 호응해 자각 없는 상실을 강조한다. · ~てしまったのではないか : 「~てしまう」(해 버리다)에 「のではないか」를 얹어 단정 대신 독자에게 되묻는 형태 — 사설·수필 단락을 맺는 상투적 수법.

  5. 店主は「まあ、だましだまし使いましょう」と笑い、油を差した羽根を、元通りに嵌め直した。

    해석 · 단어 · 구문 분석

    店主(てんしゅ)は「まあ、だましだまし使(つか)いましょう」と笑(わら)い、油(あぶら)を差(さ)した羽根(はね)を、元通(もとどお)りに嵌(は)め直(なお)した。

    주인은 "뭐, 어르고 달래 가며 씁시다"라며 웃고는, 기름을 친 날개를 원래대로 다시 끼워 넣었다.

    단어

    • 元通り — 원래대로
    • ~直す — 다시 ~하다

    구문 분석

    · だましだまし : 騙す의 연용형을 겹친 부사 — '어르고 달래 가며'. 동사 연용형 반복은 부사가 되는 조어법이다(泣く泣く·代わる代わる). · 油を差した : 기름은 差す를 쓴다 — 入れる·注ぐ가 아니다. 目薬を差す와 같은 관용 짝으로 통째로 외운다. · 嵌め直した : 嵌める(끼우다)+「~直す」(다시 ~하다). 복합동사 뒤의 ~直す는 '잘못된 것을 고쳐 다시'라는 뉘앙스로 폭넓게 붙는다(書き直す·考え直す).

설명서도 없는 낡은 기계를 앞에 두고, 의지할 것은 기억뿐이라 미덥지 않다.

💡 心+許ない — 마음이 놓일 데가 없다는 구성. 不安이 내 감정 자체라면, 心もとない는 '기댈 대상이 부실하다'는 평가가 섞인다(残高が心もとない).
구분頼りない(미덥지 않다) — 頼りない는 사람·물건이 의지가 안 된다는 대상 평가에 머물고, 心もとない는 그 때문에 생기는 이쪽의 불안까지 담는다

折り紙付き おりがみつき 명 정평이 남, 보증된 것

腕は折り紙付きだが、後を継ぐ者がいないという店は珍しくない。
솜씨는 정평이 나 있지만 뒤를 이을 사람이 없다는 가게는 드물지 않다.

💡 옛 미술품·칼에 딸리던 감정서(折り紙)에서 온 말 — 제3자가 이미 품질을 보증했다는 뜻. 太鼓判を押す가 '내가 보증한다'라면, 이쪽은 '보증서가 붙어 있다'.
구분眉唾(미심쩍음) — 정반대 축 — 折り紙付き는 보증이 붙은 것, 眉唾는 진위가 의심스러운 것
